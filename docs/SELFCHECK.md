# 10 问自查（发布前必须过）

机器能查的（字数/结构/图片/禁词）交给脚本；这 10 个问题机器查不了。

**10 问全过，才允许提交草稿。**

| # | 问题 | 不过怎么办 |
|---|---|---|
| 1 | takeaway 在前 300 字内出现了吗？ | 把结论提前，砍掉铺垫 |
| 2 | 读者是谁、卡在哪一步？具体到能对号入座 | 加一句场景化描述 |
| 3 | 有没有一条“今天就能照做”的动作？ | 补一个可执行步骤 |
| 4 | 全文是不是只有一条判断链？ | 拆成两篇，或砍掉最弱的一条 |
| 5 | 小标题是不是判断句？ | 改成“X 决定 Y”的句式 |
| 6 | 有没有一处真实犹豫或边界？ | 补一句“我没验证过”“不一定适合你” |
| 7 | 有没有具体数字或例子？ | 换成数量、时长、金额、次数 |
| 8 | 结尾提问能引来回答吗？ | 换成“你卡在哪一步 / 你现在是多少” |
| 9 | 有没有暴露未公开信息？ | 删，或用占位符 |
| 10 | 如果读者只截图一段，会截哪段？那段存在吗？ | 补一段可被独立引用的内容 |

## 强制做法

把答案写进文章目录的 `selfcheck.md`，10 条都打 ✅ 才算过：

```markdown
| # | 问题 | 结果 |
|---|---|---|
| 1 | takeaway 在前 300 字？ | ✅ 第 2 段 |
| 2 | 读者是谁？ | ✅ 刚学查词、被数字差异搞晕的人 |
| 3 | 今天能照做？ | ✅ 四步取数 + 三条设置 |
| 4 | 单条判断链？ | ✅ 为什么不同 → 不能比 → 怎么取 |
| 5 | 小标题判断句？ | ✅ 已改 |
| 6 | 真实犹豫？ | ✅ “我吃过一次亏” |
| 7 | 具体数字？ | ✅ 1200 / 2400 / 5600 |
| 8 | 结尾提问？ | ✅ “你用几个工具？” |
| 9 | 未公开信息？ | ✅ 无 |
| 10 | 可截图一段？ | ✅ “数字是线索，不是证据” |
```

## 脚本检查

```bash
python3 scripts/check_selfcheck.py selfcheck.md
```

退出码：`0` 通过 / `1` 未完成 / `2` 缺文件。

## 为什么必须做

机械检查只能告诉你“格式对不对”；10 问回答的是“这篇值不值得发”。

两者都过，才提交草稿。
